Si tus fotos son .jpg o .png, cambia el campo "imagen" de cada producto
en backend/lista_productos/productos.js y vuelve a ejecutar:

    cd backend
    npm run lista_productos

Si usas el servidor de producción en el puerto 3000, ejecuta también:

    npm run build --prefix frontend

Recomendado: 600x400 px, fondo blanco o transparente, producto centrado.
